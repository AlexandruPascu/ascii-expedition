# Game source

Source code for the EA workshop terminal-game project. See the [main README](../README.md) for build instructions, controls, and attribution.

The README originally supplied with this folder described [abuwarez/my-first-game](https://github.com/abuwarez/my-first-game) as the support repository for the C++ game-development workshop at EA. That reference is retained as workshop credit; the precise authorship of individual parts of this version is no longer known.
